# PROGRESS — Yanabee competition app

Blueprint: `SPEC.md`. Each `[ ]` item is one vertical slice, built in the order **Database → Backend API → Frontend
UI → Tests**. A slice is done only when the full suite is green and the site is rebuilt. Slices marked 🔒 need
something from the owner first.

## Built (foundation: do not rewrite)

The VAPID keys were made by the function on its first call and kept in `yb_push_config`, which only the service role reads; the private key never passed through the chat or the repo. At most 5 phones a person. Verified live: tables closed to anon and authenticated, the function refuses posts without the secret (401).
